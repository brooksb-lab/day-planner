Set up

Paste your Google OAuth Client ID. It connects this app straight to your Google Calendar and keeps your to-dos in a private file in your Google Drive. It's stored on this device only.

  1. console.cloud.google.com → new project
  2. Enable Google Calendar API and Google Drive API
  3. OAuth consent screen → External → add yourself as a test user
  4. Credentials → OAuth client ID → Web application → Authorized JavaScript origin:
